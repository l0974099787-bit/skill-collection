# ❓ 常見問題 (FAQ)

## 一般問題

### Q: 如何下載 skills？
**A**: 訪問 [Skills 列表](../SKILLS.md) 頁面，點擊相應 skill 的下載按鈕。

### Q: 下載的文件是什麼格式？
**A**: 所有 skills 都以 `.zip` 格式提供，需要解壓後使用。

### Q: 這些 skills 免費嗎？
**A**: 是的，所有 skills 都是免費提供的。

### Q: 如何安裝 skill？
**A**: 
1. 下載 `.zip` 文件
2. 解壓到目標目錄
3. 閱讀 `README.md` 文件並按照說明操作

## 技術問題

### Q: 支持哪些操作系統？
**A**: 請查看各 skill 的系統要求說明。

### Q: 如何報告問題或建議？
**A**: 請在 [GitHub Issues](https://github.com/l0974099787-bit/skill-collection/issues) 中提交。

### Q: 可以修改 skills 嗎？
**A**: 可以，根據相應的開源許可證進行修改。

## 更新與支持

### Q: Skills 多久更新一次？
**A**: 更新頻率因 skill 而異，請查看各 skill 的更新日誌。

### Q: 如何獲得最新的 skill 版本通知？
**A**: 點擊 GitHub 倉庫的 "Watch" 按鈕來接收通知。
